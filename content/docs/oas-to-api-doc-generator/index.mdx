Paste or upload an **OpenAPI (OAS) JSON** document, choose the operations to render, and preview the documentation using the same Fumadocs OpenAPI renderer as the rest of this site. References to companion files such as `Common.json` are merged in automatically, so split product specs work as well as portable ones. When you are satisfied, download the preview as standalone HTML or as the merged portable OAS.
